01 · Sobre mí

Código prolijo para sitios que funcionan

Soy desarrollador front-end en Chile y trabajo de forma remota. Me formé en desarrollo web en Coderhouse, donde construí sitios completos con HTML semántico, CSS moderno, SCSS y Bootstrap, publicados con Git, GitHub y Netlify.

Me enfoco en que cada sitio no solo se vea bien: que funcione en cualquier pantalla, sea accesible y esté preparado para que Google lo entienda desde el código.
